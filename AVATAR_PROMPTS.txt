================================================================================
AVATAR PHOTO PROMPTS — 22 versions of one face
================================================================================

HOW TO USE

  1. Attach portrait.png (the ORIGINAL base photo) to EVERY prompt.
     Never generate a variant from a previous variant — the drift compounds.
  2. Paste one prompt below, unchanged.
  3. Save the result under the filename given in [FILE: ...].
  4. Put it in:  C:\Users\User\desktop\sha256\avatars\my_avatar\
  5. Check it before using:
        python scripts/check_avatar_photos.py avatars/my_avatar/portrait.png <new file>

  The engine uses whatever files are present. A missing one is not an error —
  the avatar simply does without that expression.

  ALREADY DONE: portrait.png, portrait_smile.png, portrait_mouth_open.png,
                portrait_eyes_closed.png, portrait_brows_up.png,
                portrait_turn_left.png, portrait_turn_right.png

  IF THE LIST IS TOO LONG, generate these nine first — they cover most of what
  is visible in an ordinary conversation:
        3, 4, 6, 10, 11, 12, 13, 19, 20

================================================================================
IF YOU WANT TO REPLACE ONE YOU ALREADY HAVE
================================================================================

The engine measures each photograph's own mouth opening and treats the widest as
"fully open", so a wider or more expressive replacement simply extends the
range. Nothing in the code needs changing.

  portrait_smile.png       — a broader smile shows more teeth to work with
  portrait_mouth_open.png  — a wider opening extends how far you can open

Superseded files can be renamed (e.g. portrait_smile_modest.png) rather than
deleted; the engine only reads the names listed above.


================================================================================
WHAT EACH ONE FIXES
================================================================================

  closed smile      a warm smile borrows the teeth photo and looks toothy
  "oh" and "ee"     every vowel looks like the same open mouth
  pressed lips      "m" and "b" do not close the mouth
  gaze, four ways   the avatar stares ahead while you read your screen
  wide eyes/squint  the eyes only ever have one size
  brows down        only surprise is available, never concentration
  far turns         past about 25 degrees the face stretches
  tilts             nodding stretches the face vertically
